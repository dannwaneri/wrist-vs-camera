Try it in one minute, no install

This page plays a recorded session from a real run: Device Readiness, frame rate, live pulse and breathing, the upload meter, and the end result. No camera, no key.

Measure yourself (about 5 minutes)

Live measuring needs the app on your own computer, because the Presage SDK runs as native code there. You need Node.js 20+, a free Presage key, and a camera that gives 25+ fps.

git clone https://github.com/dannwaneri/wrist-vs-camera.git
cd wrist-vs-camera
npm install
npm start

Then open http://localhost:4317. Code and test results: github.com/dannwaneri/wrist-vs-camera

1. Add your Presage key

This app uses the Presage SmartSpectra SDK. It needs a free API key from physiology.presagetech.com. The key stays in a file on this computer. The page never sees it again.

No key?

2. Check your setup

The app first measures how much your computer uploads while idle (20 s, camera off). Then the SDK's Device Readiness check asks whether this camera can measure here. Then the measurement starts.

What leaves this computer: no video or images. The SDK sends your key check and usage to Presage. Presage's docs say it also sends your measured numbers (this app requests pulse and breathing, not HRV) to Presage about once a minute, for its LLM Insights feature. I found no setting to turn that off.

What worked in my tests
  • A laptop webcam at 10 fps failed. The SDK needs 25+ fps.
  • A phone used as a USB webcam gave 30 fps.
  • Window daylight worked. Fluorescent light on a generator did not.
  • Sit still. Only one face in view. Head and upper chest in the picture.

Count your own pulse

Put two fingers on your wrist, below the thumb. Press Start, then count the beats in your head for 60 seconds. Keep still. At the end, type your number.
Option: press the Space bar on each beat instead. In my test, tapping made me move and the camera lost quality.

Result
